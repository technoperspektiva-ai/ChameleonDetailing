ChameleonDetailing v1.1.48 UPDATE — Localized Reports + Order Payments

1. Excel reports now follow each staff member's selected management language: Ukrainian, Polish or English.
2. The selected language is read from users.management_language, with users.language as fallback.
3. Workbook sheet names, column headers, dashboard labels and Telegram report captions are localized.
4. Common report values are localized too: order/payment statuses, Cash/Card, first/repeat client and yes/no flags.
5. The language choice is personal: Owner/Admin/Manager can receive the same report type in different languages.
6. Order cards keep the v1.1.47 Payments flow: Payments → Paid → Cash/Card.
7. PAID payment rows continue to feed Payments/Revenue Excel reports and Google Sheets snapshots.
8. Google Sheets control panel already uses UA/PL/EN interface localization; Sheets tab schema remains stable for automation.
